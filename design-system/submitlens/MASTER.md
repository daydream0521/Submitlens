# SubmitLens 设计体系

依据：PRD 的大学生竞赛/课程、本地桌面工作台定位；UI_COPY 的精简文案；阶段 1 的项目列表与纯文本保存范围。

## UI UX Pro Max 生成与适配

重新安装技能后已运行 `student productivity workspace minimal --design-system`：匹配 Flat Design 和生产力 Web 应用，推荐无渐变/阴影、简单颜色反馈，适合本项目。随后以 --persist --output-dir . 运行，工具保留已有 MASTER。保留下述经 Frontend Design 审查的冷灰/深蓝配色，替代通用青绿/橙色方案；中文系统字体替代无中文覆盖的 Plus Jakarta Sans，避免外部字体依赖。技术栈为用户指定的 React Web。

## 最终规范

- 背景 #F3F6F9；纸面 #FFFFFF；正文 #202D40；次要文字 #59697D；操作 #2454A4；边界 #CFD8E3。错误另用 #B42332。
- 字体：Segoe UI、Microsoft YaHei、系统无衬线；正文 16px/1.6，辅助 14px，标题 28px/1.3、600。无外部字体请求。
- 4/8px 间距体系；内容最大 1120px；桌面侧栏 224px；控件圆角 6px；不使用装饰阴影、渐变。
- 列表左对齐，名称允许换行；竞赛/课程为文字类型，不制造进度或验收统计。
- 编辑区保留段落，行高 1.8；保存动作与真实保存结果相邻。
- 键盘焦点清晰，控件至少 44px，表单显式标签；对话框可取消，删除明确确认。
- 移动端侧栏变顶部导航，列表改纵向排列；无装饰动画。

```text
首页：品牌栏 | 我的项目          新建项目
            | 名称 / 类型 / 更新时间 / 操作
详情：项目名 | 任务要求                  保存
      导航  | 粘贴文本
            | 多行原文编辑区
```

## Frontend Design 审查

取消通用 SaaS 的 Hero、统计卡片与营销说明；以任务原文编辑空间作为核心。辨识点集中在深蓝项目侧栏和档案式列表，其他元素保持安静。成果验收与交付中心只展示导航文字及“未实现”，不提供假操作。依据 UI_COPY 删除无助于当前操作的说明。

## 阶段三适配

成果页沿用同一配色、排版与间距；新增覆盖分组、筛选、展开文件的反向关联及上传进度，不引入另一套 GUI。覆盖数仅统计当前已确认要求的选定证据；草稿与原文变更待处理项独立列出。UI UX Pro Max 的 file upload progress 查询返回进度反馈建议，成果上传采用实际 XHR 字节进度。JanusTrace 仅参考覆盖与追踪的信息架构，未复制源码。

## 阶段四适配

成果页顶部显示验收状态与真实预检入口，证据覆盖独立保留；正式要求按失败、待复核、待检查、通过排列。检查详情采用实际/要求/依据/时间的紧凑定义列表；内容确认标明人工来源，不将覆盖视为检查通过。沿用 UI UX Pro Max 的请求反馈规则，无新增视觉库。
