# SubmitLens 设计体系

依据：PRD 的大学生竞赛/课程、本地桌面工作台定位；UI_COPY 的精简文案；阶段 1 的项目列表与纯文本保存范围。

## UI UX Pro Max 生成与适配

使用技能的无障碍、表单、导航、排版规则人工整理。实际执行搜索命令失败：本机 scripts 是路径文本，指向的源目录不存在；未伪称运行成功。采用 React Web，忽略技能中与本项目冲突的 React Native 假定。

## 最终规范

- 背景 #F3F6F9；纸面 #FFFFFF；正文 #202D40；次要文字 #59697D；操作 #2454A4；边界 #CFD8E3。错误另用 #B42332。
- 字体：Segoe UI、Microsoft YaHei、系统无衬线；正文 16px/1.6，辅助 14px，标题 28px/1.3、600。无外部字体请求。
- 4/8px 间距体系；内容最大 1120px；桌面侧栏 224px；控件圆角 6px；不使用装饰阴影、渐变。
- 列表左对齐，名称允许换行；竞赛/课程为文字类型，不制造进度或验收统计。
- 编辑区保留段落，行高 1.8；保存动作与真实保存结果相邻。
- 键盘焦点清晰，控件至少 44px，表单显式标签；对话框可取消，删除明确确认。
- 移动端侧栏变顶部导航，列表改纵向排列；无装饰动画。

```text
首页：品牌栏 | 我的项目          新建项目
            | 名称 / 类型 / 更新时间 / 操作
详情：项目名 | 任务要求                  保存
      导航  | 粘贴文本
            | 多行原文编辑区
```

## Frontend Design 审查

取消通用 SaaS 的 Hero、统计卡片与营销说明；以任务原文编辑空间作为核心。辨识点集中在深蓝项目侧栏和档案式列表，其他元素保持安静。成果验收与交付中心只展示导航文字及“未实现”，不提供假操作。依据 UI_COPY 删除无助于当前操作的说明。
