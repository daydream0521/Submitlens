## 已完成

- 项目内交付中心复用 requirements/artifacts/checks，不重复预检。正式必交分通过/不通过/待复核/待检查，未确认、stale、source_issues 单列待处理。默认按验收选定 ID 去重，可选择额外项目文件，预览与 ZIP 一致。
- POST /export 支持 JSON 与原生表单文件 ID 集合；仅当前项目文件可用。ZIP 固定根报告与 materials/<UUID>/<原名>，同名不覆盖，每个 artifact 只写一次。危险路径部件不会直接用于归档路径。
- 报告明确分开验收选定与实际打包，并记录未包含的证据；待处理项不提供自动通过结论。没有素材可导出真实报告，界面明确材料为空。
- ZIP 用标准库在磁盘临时文件中生成，使用 Zip64、ZIP_STORED，直接从文件写入，不整包读入服务端或前端 RAM。HTTP 分块发送，完成/异常均清理临时文件。下载完成状态登记在最后响应块发送前，失败恢复原值。
- 最小过期数据为两个项目时间字段。任务/要求、证据选择、删除替换、复核和重新预检改变后提示重新导出；未选定候选上传不标过期。报告/ZIP 发送期间有新修改也不会错误清除提示。状态经实际进程重启验证。
- 确认清单后有「去上传成果」，成果页有「交付中心」，交付页按需返回指定要求；已有导航未重构。
