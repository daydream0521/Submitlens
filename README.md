# SubmitLens · Codex 启动包

用于 2026 年传智杯「AI 创新应用 / Vibe Coding」个人赛项目开发。不是已完成的应用代码。

## 文件说明

1. `PRD.md` — 产品范围、用户流程、功能要求与 MVP 验收口径。
2. `UI_COPY.md` — 全界面精简文案规范、文本预算与示例。
3. `ENGINEERING.md` — 技术选型、最小数据模型、API 顺序与开发时间表。
4. `ACCEPTANCE.md` — 传智杯真实规则提取对照、课程案例结构和关键操作检查。
5. `CODEX_STEP1.md` — 可直接交给 Codex 的第一阶段指令。

## 如何开始

1. 在新的或现有的 SubmitLens Git 仓库中，创建 `docs/`，将 `PRD.md`、`UI_COPY.md`、`ENGINEERING.md`、`ACCEPTANCE.md` 放进去。
2. 将 `CODEX_STEP1.md` 的内容完整交给 Codex。
3. 第一阶段只验收「项目创建 → 文本说明输入 → 持久化读取」，通过后再推进文档上传与 AI 要求提取。
4. 从第一阶段开始自然保留真实 Prompt 对话、Bug 修复往返和 Git 提交。

## 比赛来源

需求中的赛事材料限制来自用户上传的《赛道介绍.md》：省赛提交截止 2026-11-18；5–8 分钟 MP4 视频、≥2 分钟 AI 协同过程、PDF 文档 ≤30 页、至少 3 组核心功能的 Prompt 迭代记录。详细引用见 `PRD.md` 与 `ACCEPTANCE.md`。
